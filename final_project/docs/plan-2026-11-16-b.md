## 2. 鱼：让"程序生成"看得见

**问题**：并排 6 条鱼只说明"它们不一样"，没说明"怎么长出来的"。

**改法：图鉴里做一个"生长过程"，和兽的形态编辑器同级。**
- 左栏：一条生长步骤条（可以拖动、也可以自动播放）：
  1. 脊线（一条线，长度 = 体长）
  2. 轮廓（`fishProfile` 的曲线：钝头、最高点、尾柄）——画出控制点
  3. 截面（横截面椭圆，从头到尾变窄）
  4. 鳍（按规则放：背鳍在最高点后、胸鳍在鳃后、尾鳍在尾柄末端）
  5. 玉斑（种子撒点 → 斑块长大，边缘按种子起伏）
  6. 游动（摆尾由体长和速度算出）
- 右栏：和兽一样的滑杆，用形象的名字：**长短**（体长）、**胖瘦**（体高）、**尾形**（浅叉 ↔ 深叉）、**斑纹**（少 ↔ 多）、**鳍**（短圆 ↔ 长飘）；"新形态"和"恢复出生形态"两个按钮。
- 删掉"同种子家族"。

**圆润**：鳍的外缘改成曲线（贝塞尔/样条采样）而不是折线；尾叉的凹口也做成圆弧；鳍加一点厚度和向外弯曲；身体截面从椭圆改成稍微"方圆"一点（superellipse），鱼腹更饱满。鳞：不再画单独的鳞片，改成在身体颜色里叠一层很淡的鳞纹（按位置计算的弧形纹），只在近处看得见。

**游动不写死**：
- 摆尾频率 = 0.3 × 游速 ÷ 摆幅（斯特劳哈尔数约 0.3），摆幅 ≈ 0.2 × 体长。大鱼慢摆、小鱼快摆，自然由规则得出。
- 身体整体做一点 S 形波动（从头到尾振幅增大），而不是只摆尾巴。
- 路线：在潭里按水流场 + 三条简单规则（逆流保持、避开浅水和瀑布落点、和别的鱼保持距离）走，代替现在固定的来回往返。

## 3. 兽的参数：高矮胖瘦 + 分叉

| 现在 | 改成（中 / 英） | 两端 |
|---|---|---|
| 体态 Build（bulk） | **胖瘦** Build | 瘦 ↔ 胖 |
| 躯干厚度 Body depth | **腰身** Belly | 细腰 ↔ 圆肚 |
| 身形 Height（stature） | **高矮** Height | 矮腿 ↔ 长腿 |
| 角姿 Horn sweep | **角的姿态** Antler sweep | 平展 ↔ 上扬 |
| 分枝层级 Branch tiers | **分叉代数** Antler growth | 0 · 1 · 2 · 3 代 |

- 每个滑杆两端加一个小剪影图标（瘦/胖、矮/高），一眼看懂。
- **分叉代数**用分枝系统来讲：旁边一个小图，画出规则（主枝 → 主枝 + 一根侧枝），点 0/1/2/3 时，小图和模型上的角一起"长一代"，可以播放生长动画。说明一句："每一代，每根枝的末端按同一条规则再分一次叉。"

## 5. 栖居地（请挑方案）

三个低保真方案（会话里有图）：

- **A 落石成窝**：崖上按坡度和裂隙选出松石，沿梯度滚落、碰到就停、互相搭住，最大的空隙成为窝（检查净高、干地、背风开口）。过程可以直接播放出来。石头是圆润的块，不再是硬方块。
- **B 崖脚风蚀龛**：背风的坡脚被一层层"蚀"进去，形成挑檐，卧处在檐下。最"原生"，和山融为一体；但高度图做不出挑檐，要额外生成一块檐的网格。
- **C 松根灌丛巢**：从坡上的老松出发，用分枝系统让根和灌丛枝长成拱，兽睡得越久窝越深。和鹿角共享一套分枝算法。

推荐 **A**，或者 **A + C**（落石成窝，松根从石缝长出来）：过程最容易"演"出来，形态最柔和，可以和课上的分枝联系起来。

## 结果（2026-11-17）

主人确认：栖居地不用落石，改为**林下、树荫里的天然岩窝**，形状由代码生成，不必有复杂规则。其余按顺序开始做。

1. **头像**：需求卡头像单独取景（`CreatureThumb portrait`），用脚本把整只兽投影到镜头里核对：左右 −0.69…0.72，上下 −0.68…0.76（框是 ±1），完整且居中。
2. **兽的参数**：改名为胖瘦 / 腰身 / 高矮 / 角的姿态 / 分叉代数，文字移进 `strings.ts`（`morph.*`）。
   **鹿角改成真正的分枝系统**（`creatureMorph.ts` 的 `ANTLER_RULE`、`growAntler`）：一条规则反复执行，每一代、每根枝各长出一根新叉（在它的 1/2、3/4、1/3 处），长度约为它的 56%，交替朝上、朝前，粗细每代乘 0.62。0 代是一根主枝，3 代最多 8 段。编辑器里的小图（`AntlerRule.tsx`）用同一个函数画出 0→当前代的生长过程。`check-morph-rework`：整个滑杆空间 0 个问题，角冠最高 1.77 m。
3. **调试面板合并**：设置抽屉里"运行生灵"和"生灵调试"合成一块"生灵 · 时间与痕迹"：运行、倍速；痕迹（路径、脚印、四脚，悬停提示"只有白玉兽有；溪灵不留脚印"）；目标（状态与目标、饮水点、卧处）；骨架和开发项收进"更多"。
4. **思考气泡**：兽走向目标时头顶出现一个图标（水滴、草叶、月牙），到了就消失；卡片上去掉"想找草吃"那一行，只留在做什么 + 心情词。鱼的心情词也按同一规则来自体力（"有些累了""筋疲力尽"）。
5. **鱼**：
   - 形态规则集中到 `fishForm.ts`：轮廓、玉斑、鳍的外形、游动规则。
   - 鳍和尾的外形改成闭合的 Catmull-Rom 曲线（圆角），截面改成圆角方形（superellipse）。
   - **游动由规则算出**：巡游速度 = 体长 × 0.4–0.8 / 秒；摆尾频率按斯特劳哈尔数（频率 × 摆幅 ÷ 速度 ≈ 0.3），大鱼摆得慢；身体有一道从头到尾逐渐变大的波。路线不再是写死的往返：巡游时朝种子选的深水点游，歇息时面向水流并留在出生地附近；前方水浅就转向潭心，靠近瀑布落点就躲开，靠近别的鱼就避开；每秒最多转 1 弧度。
   - **图鉴**：删掉"同种子家族"；左栏是六步"生长过程"（脊线 → 轮廓 → 截面 → 鳍 → 玉斑 → 游动），都由同一套规则画出；右侧是会摆尾的模型、选中步骤的大图和一句规则、五个滑杆（长短、胖瘦、尾形、斑纹、鳍）、"生成新形态 / 恢复出生形态"；下面是需求卡和数字（含摆尾频率）。
6. **检查**：`tsc` 无错，`vite build` 通过，`check-world` 684 / 7 / 42 规则全部成立。

**栖居地**：给了三种"林下岩窝"的生成方式（岩块簇 / 整块岩壳 / 斜靠岩板），推荐整块岩壳，等主人挑。

## 第二轮修改（2026-11-17）

1. **需求阈值对齐**：
   - 原来兽只在当前动作结束时才检查需求，所以数值越过竖线后还会躺一阵，到 40 左右才动。
   - 现在像 Sims 一样：休息时只要水分或饱腹（有草可吃时）越过竖线，1.5 秒内就起身（`dwelling.ts` 的 `WAKE_S`）。
   - 实测：水分正好在 50 时起身去喝水。
   - 卡片上的心情词只在越过竖线后才显示"饥饿/口渴"；黄色区间仍显示"安然"。
2. **鱼的编辑器**：
   - 改成和白玉兽一样的布局：左边大模型（真实尺寸，长短滑杆看得出变化，按体长规则摆尾），右边五个滑杆，直接改模型。
   - "结构"按钮在模型上画出脊线、截面环和玉斑的种子点，对应兽的"骨架"。
   - 删掉了六步图、左栏、需求卡和数字表。
3. **栖居地：整块岩壳**（`rockShell.ts`、`scripts/check-rock-shell.ts`）：
   - 一块用 SDF + marching cubes 生成的圆石，从拱形洞口掏出洞穴。
   - 种子决定圆石大小与倾斜、3–5 个鼓包、大尺度外鼓起伏、表面风化噪声。
   - 规则：洞腔是兽使用空间外扩一圈，只会被噪声撑大、不会缩小；除洞口外岩石至少 0.35 m 厚，不够就按比例放大；洞口是拱形，宽高够兽通过。
   - 外圈加一圈障碍圆，兽不会穿进岩石。
   - 检查：8 个种子全部通过；`check-world` 684 / 7 / 42 规则全部成立。
   - 尺寸约 5–6.5 × 5 × 4 m，生成约 0.55 秒。
   - 旧的岩板代码（`shelterGeometry`）还留着，没有删。

**还没做**：岩窝目前放在原来的"家"附近（开阔地），还没有改到树林下面。
