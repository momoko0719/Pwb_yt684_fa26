## 结构：一层一层"走进"白玉岛

整页是一条往下滚动（或点击"下一层"）的旅程。每一层占满一屏，层与层之间用"穿门"的过渡：画面放大、云雾掠过，进到下一层。最后一层就是真正的岛。

| 层 | 内容 | 画面 |
|---|---|---|
| 0 · 云海 | 只有标题"白玉岛 / White Jade Island"和一句话："云海之上的一座白岛。生灵栖居之处，石头渐渐成玉。"；一个"进入"按钮 | 整屏：黄昏或夜里的岛（你发来的第 3、4 张那种），云雾缓缓移动 |
| 1 · 来处 | 神话来源：《列子·汤问》里的归墟与五山（蓬莱是第一座岛，白玉岛是这一座）；《山海经》的写法（每种生灵一段：形、名、性）；青绿山水与敦煌壁画的颜色 | 古籍和画作的局部（公开领域的图），旁边一句注解 |
| 2 · 规律 | 一句话一个规则：地形由高度场生成；水往低处流成溪和潭；地带决定草、灌丛和树长在哪；生灵走过、卧过的地方，石头变玉 | 每条规则配一个小循环动图或前后对比图（比如接触图从白到玉） |
| 3 · 生灵 | 白玉兽：两只，名字随机（青珩、寒玉……）；各有性格；需求卡（参照《模拟人生》）；轮流喝水、结伴吃草。溪灵：鱼群的三条规则（避让、对齐、聚拢） | 需求卡和鱼群俯视图做成网页上真的会动的小组件（不是截图）；配兽喝水、走路的画面 |
| 4 · 一天 | 兽一天的轨迹：路线、脚印、玉色的变化 | 一张俯视的轨迹图，可以拖动时间轴 |
| 5 · 先例 | 游戏和作品先例：模拟人生、Rain World、Shelter、ABZÛ、旷野之息、看火人……每张卡一句"它怎么做 → 我们拿来做什么" | 卡片墙，悬停翻面 |
| 6 · 入口 | 一扇门："走进白玉岛" | 点击：镜头穿过门 → 跳到 World |

文字中英双语（跟随语言切换）；配色和字体沿用白玉 UI。

## 结果：骨架（2026-11-19）

主人选的参考是 MotionSites 上一个"滚动驱动的视频页"：
- 整屏画面固定，滚动控制画面推进；
- 文字分段，前一段完全淡出后下一段才出现；
- 文字直接压在画面上；
- 右侧有进度点。

只借这套机制。对方的品牌、文案和视频都不用；配色用白玉 UI，画面用我们自己的岛。

1. **画面**：从 3D 画布直接截取（不带界面），放在 `public/ideas/`：
   - 黄昏全景（开篇）
   - 晨光里的山与水池（怎么长出来）
   - 正午水边（溪灵）
   - 岩窝里的兽（白玉兽）
   - 夜景（来处、进入）

   滚动时这些画面交替淡入淡出，并缓慢推近。
2. **六段**（`pages/Ideas.tsx`），每段一两句描述，加一个小组件：

   | 段 | 文字 | 小组件 |
   |---|---|---|
   | 开篇 | 白玉岛；"一座漂在云海上的岛。地形、水、草木和生灵，都由规则生成。" | — |
   | 怎么长出来 | "一个种子，四步长成。" | 四张步骤卡：高度场 → 水 → 分区 → 草木与生灵 |
   | 溪灵 | "一群六到十条，每条鱼只遵守三条规则。" | 实时鱼群小图，用的就是岛上的 `schoolPull` 规则，标出三圈范围 |
   | 白玉兽 | "两只兽，各有名字、家和性格。" / "饿了吃草，渴了喝水，累了回岩窝。" | 和岛上同一个组件的需求卡（数值在动）；"栖居成玉"小图：脚印把格子染成玉 |
   | 来处 | — | 两张卡片："典籍与绘画"（列子·汤问、山海经、千里江山图、敦煌壁画）和"游戏"（模拟人生、雨世界、ABZÛ、Shelter、旷野之息），每条一行说明拿来做什么 |
   | 进入 | "整座岛在浏览器里实时运行。" | "进入白玉岛 →" 按钮 |

3. **机制**：
   - 滚动进度每帧向真实值缓动（和参考一样，避免跳帧）；减少动态时直接跟随。
   - 每段的子元素依次上浮（0.8 秒）。
   - 右侧六个点可以点击跳转；开篇右下有 ↓。
   - 中英文都走 `strings.ts`。
4. **读不清的地方**：开篇和"进入"的文字放到画面上方的天空里；"来处"改成半透明卡片。
5. 旧的 Ideas 内容（`content/ideas.*.md`）不再显示，文件还在。

**下一步**：

- 再决定要不要做"一层层点进去"的穿门过渡（现在是滚动推进）。

## 第二轮：按主人反馈打磨（2026-11-19）

主人的意见：
- 灰字、黑字直接压在画面上不好看，显得局促；
- "四步"看不懂；
- 鱼像小虫子；
- 白玉兽那一屏的两块板最清楚，其他屏都照这个标准做；
- "来处"和最后一屏用的是同一张图；
- "来处"要加链接和小图，游戏要加图标。

改动：
1. **文字都放到纸色卡片上**，和白玉兽的面板一样：半透明纸底、模糊背景、留足内边距。开篇标题、四步、溪灵、白玉兽、进入，全部如此。行距加大到 1.75，小标题改成玉色。
2. **四步改成四张会动的小图**（`pages/ideas/GrowSteps.tsx`）。同一块用种子生成的山谷，每张比前一张多走一步：
   1. 地形：噪声生成的高度图，用光影和等高线表现，光的方向缓缓转动；
   2. 水流：雨滴沿最陡的方向一格一格流下，汇成溪，流进潭（用 priority flood 保证每一格都能流到潭里）；
   3. 分区：按高低、坡度和离水远近分成湿岸、石坡、林地，从左往右扫一遍着色，下面附图例；
   4. 生长：松树依次长出，湿岸长草，岩窝里的兽走到潭边喝水再回去，潭里有鱼。

   每张下面只有一句说明：步骤名分别是"地形 / 水流 / 分区 / 生长"。
3. **鱼群小图重做**（`pages/ideas/FishPond.tsx`）：
   - 俯视的圆潭，画面跟着鱼群漂移，水底有小石子，能看出鱼在游；
   - 鱼按岛上溪灵的样子画：白身、玉色斑、尾巴摆动、水底有影子；
   - 红色那条带路，三个虚线圈是它的三条规则；
   - 左边的图例写明每条规则（"太近：避开"等）和它的范围（几倍体长）。
4. **换了两张图**：
   - 白玉兽：正午、稍高的机位，能看到松林、溪和两只兽各自的岩窝；
   - 来处：晨光里的林间溪流。

   现在六屏用的是五张不同的图，只有"进入"沿用夜景。
