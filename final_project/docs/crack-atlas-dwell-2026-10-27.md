## 一、地表横向破口

### 1. 原来我看到了什么
近地视角出现横向断层，局部像能透出后面的东西。

### 2. 实际原因是什么，有什么证据
先按五类区分（脚本探针 `probe-terrain-seam.ts`）：

| # | 结论 | 证据 |
|---|------|------|
| 1 邻接块高度不一致 | **不太像主因** | CPU 高度场是双线性连续；邻格跳变是地形本身起伏，不是接缝空洞 |
| 2 LOD／变形裂缝 | **可能仍有**（岸边尤甚） | 既有文档与线框经验：窄溪岸强制细网格切换时可见方块边；**本轮未冻 LOD 目视** |
| 3 与水面叠层 | **次要可能** | 水面单独网格、不写深度；透视岸可露出粗三角河床 |
| 4 近裁剪／深度精度 | **已确认可加剧** | 漫游近裁剪曾为 **0.05 m**、远平面 5000 → 深度比 **100000**；Orbit 为 0.5→10000。眼高漫游贴岸时 z 冲突会像「切开／透底」 |
| 5 仅材质不连续 | **已确认可看起来像裂缝** | 风化噪声近／远两套在 50–85 m 硬切换，色带可呈水平线；线框下几何仍完整 |

**未**用模糊、加厚遮罩、抬高相机来遮。

### 3. 具体改了什么
- `Walk.tsx`：漫游近裁剪 **0.05 → 0.2 m**（改善深度精度，不抬眼高）。
- `cdlod.ts`：风化近远交接 **50–85 → 40–110 m**，减轻色带假裂缝。

### 4. 打开页面后应看到什么
同一位置漫游眼高贴岸／Orbit 贴近／连续缩放时，**假裂缝感应减弱**。若线框下仍有真几何缝，那是 CDLOD 岸边问题，见「未解决」。

### 5. 还有什么没解决
CDLOD 岸边真缝与水面接合的目视分类 **尚未验证**。请用 Debug→显示地块线框 + 隐藏水面对照；若裂缝跟着块边走再改 morph／选块，不要先加模糊。

状态：脚本归因通过；Walk／风化改动 **尚未目视**。

## 二、图鉴封面与压扁

### 1. 原来我看到了什么
名字有了，封面全是绿方块；松树详情像被横向拉宽或压扁。

### 2. 实际原因是什么，有什么证据
- 封面：`Thumb` 先对 canvas 取了 **2D** 上下文，再塞 WebGL → 失败落入绿色色块 fallback（**已确认**）。
- 压扁：详情相机 `aspect` 写死为 **1**，而容器约 320×220，再加 CSS `width/height !important` 拉伸位图（**已确认**）。
- 灌木曾用 `scale.z *= 0.85` 非等比压扁（加重 V 字感）。

### 3. 具体改了什么
- 离屏 WebGL 渲染封面并缓存；展示用 `<img>`，不再锁 2D 上下文。
- 详情：`ResizeObserver` 同步 renderer 尺寸与 `cam.aspect`；只移相机取景，模型等比。
- 无预览资源隐藏旋转／换样本／人形；删开发路径式废话。
- 生灵「本岛实例」改为 **BODY 实测单值**（本岛 1 只），不再抄配置区间 [1.1–1.4]。
- CSS 去掉强制拉伸预览 canvas。

### 4. 打开页面后应看到什么
植被封面应是真实模型剪影；松／灌木预览不椭圆压扁；调窗口宽、换分类、关闭重开后比例仍对。无预览项只有「定位」。

### 5. 还有什么没解决
生灵独立封面仍无场景截图管线（卡片显示「场景定位」占位）—— **尚未做**。封面／比例 **尚未目视**。

## 三、生灵当前怎么生活（通俗）

### 生成岛屿时

1. **先选饮水点，再为每个候选饮水点配家园，成对打分后取最优。** 不是先钉死一个家再找水。
2. **家园候选**：同一片干地区域里的「栖息地／开敞石地」格子；须离水 18–90 m、坡度够缓、离梯田够远、周围略有「比自己高」的遮蔽加分；栖息地额外加分。
3. **饮水候选**：区域里「到水距离」落在岸带上的干格子；站位须脚全干、可站；脖子低到能碰到 **field 算出的真实水面点**（不是软边油漆）。
4. **路线**：家与饮水点之间用 1 m 格 A* 找干路；走不通就换下一对，绝不直线过水。
5. **面板 A／B／C**：同一座岛上预先选好的 **三个固定家园点**（同一饮水体系），不是每次重抽。切 A/B/C 只改「当前偏爱的家」编号，不重跑选址。

### 模拟运行时

1. 休息倒计时结束（约 50–90 秒）→ 出发喝水。
2. 每次在附近饮水站列表里 **随机一个**（常只有主站）；不是全岛重选。
3. 喝完明确进入走回：`next = 'rest'`，目标是家附近。
4. 回到家心 **约 0.7 m** 内的可站点才躺下（`nearHome`）。
5. 每次回家落点在 0.7 m 圆内抖动，朝向略变 → 卧痕集中但不完全重合。
6. 路线失败：多留一会儿，**不**换家、不原地永久躺死；稍后重试。
7. 家 **不会**因疲劳／失败自动改；只有面板改 A/B/C 或重置。
8. 玉痕按脚／身体实际接触写入行走／饮水／休息通道；回家后同一片休息区继续累加。

## 五、灌木形体收尾

### 1. 原来我看到了什么
普遍低平、V 字展开，叶簇仍像松针喷雾。

### 2. 原因
基干俯角 55°、侧向扇开为主；实例 `scale.z*=0.85`；叶虽独立参数但仍偏喷雾排布。

### 3. 改了什么
- 短直立基干 + 上扬枝条；俯角 32°；取消 Z 压扁。
- 叶参与松针完全分离（`SHRUB_LEAF`）；0.8 m 株：叶约 **5.4×1.2 cm**，冠幅 ~1.2 m。
- LOD 三角（变体0）：近 1091／中 724／远 408。

### 4. 打开应见
图鉴样本更「有主干高度」；场景近中远同株形。蓬莱松规则未动。

### 5. 未解决
图鉴／场景目视 **尚未验证**；株形变体差异仍偏弱。

## 生灵生活逻辑（一段话）

岛生成时，程序在大片干地上先找能站稳、嘴够到真水面的饮水点，再为它挑三个坡缓、略有遮蔽、走得到的家（A/B/C）。平时它在当前家附近躺着蹭出卧痕；歇够了就沿干路走到饮水点低头喝一会儿，再走回同一个家旁边不到一米的地方重新躺下。走不通就多歇一会儿再试，不会因此搬家。脚印、喝水、躺卧都会慢慢把地面磨成玉色。
