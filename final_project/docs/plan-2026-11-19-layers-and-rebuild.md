# 方案：图层整理 + 调参不打断（2026-11-19）

主人的想法：
- 老师说过，调试图层（尤其是水流）很有用，能帮人看懂这个世界；
- 最近做的新东西还没有对应的图层；
- 现有的图层散在好几个地方，要整理好；
- 进入世界之后调地形参数，整个世界会卡住、重新加载，打断体验。第一次进入时的加载画面要保留。

问题：
1. 同一类东西分散在四个地方："外观""生灵""更多"，再加上 Leva。
2. 最有说服力的水流粒子藏在"更多"里。
3. 有些标签只有英文，或者是开发用语（比如"Region gate"）。
4. 打开一个图层后，屏幕上没有统一的图例，看不出颜色代表什么。

## 二、这段时间做了、但还没有图层的东西

数据都已经在代码里，只是还没画出来：

| 类别 | 新图层 | 画什么 |
|---|---|---|
| 地形 | 高度与坡度 | 地面按高低着色，加等高线；或者按坡度着色（陡处深）。和 Ideas 页"① 地形"是同一种语言 |
| 水 | 水系图 | 三层潭和出水口画成节点，溪流按水量粗细画线，瀑布落点标圈。看清楚"水先是一张图，然后才是一层表面" |
| 生灵 | 栖息地 | 两只兽各自的家（A/B/C 候选）、岩窝、饮水点（轮流用的几个站位）、吃草的草场（按剩余草量深浅，吃了会变浅，慢慢长回来） |
| 生灵 | 两只兽的关系 | 跟随时连一条线，让路时标出让路的一方 |
| 鱼 | 岛上鱼群 | 在岛上的潭里直接画：领头鱼、三圈范围、当前目标点、游/歇状态 |
| 成玉 | 成玉程度 | 把接触图（走、饮、卧三种）单独铺成一张热图，和地面的玉色对照 |

## 三、怎么整理：一个独立的"图层"面板

不再放在设置里，单独做一个"图层"按钮（地图按钮旁边）。打开后是一张卡片，分四组：

```
┌ 图层 ─────────────────────────┐
│ 地表（一次选一个）                │
│  ○ 原貌  ○ 高度  ○ 坡度  ○ 分区   │
│  ○ 草被密度  ○ 成玉程度           │
│ 地形   □ 山褶                     │
│ 水     □ 水流粒子  □ 水系图        │
│ 生灵   □ 栖息地  □ 路线与脚印      │
│        □ 状态与目标  □ 两只兽关系   │
│        □ 鱼群                     │
│ 尺度   □ 尺度对照                  │
└──────────────────────────────────┘
```

- **地表**这一组只能选一个，因为它们都是给地面换颜色。其他组是叠加在上面的线和点，可以同时开。
- 每个图层带一个小图标和一句话说明（中英文都有）。
- 开了哪些图层，左下角就出现一张合并的图例。
- 技术向的（LOD 线框、山褶的分步调试、骨架）留在设置 → 更多，不进这个面板。

## 四、调参不再重新加载

现在的做法：参数一变，先把整座岛清空，显示加载画面，等后台重算完再重建。所以每次调参都会闪一下。

改成：
1. **第一次进入**（以及换一座岛，也就是换种子）：保留现在的加载画面。
2. **进入以后调地形、水、岛底参数**：
   - 旧的岛留在原地，镜头不动；
   - 右下角出现一个小提示："正在重塑地形 42%"；
   - 后台算好后一次换上新岛，不清空、不闪。
3. **找出切换那一下的卡顿**：新地形到了以后，主线程还要重新种树、长草、找栖息地、生成岩窝的形状、放鱼。我先逐项测时间，把最慢的几项挪到后台，或者分到几帧里做。

注意：地形变了，兽的家、饮水点、草场都会重新找，所以两只兽会重新开始一天。这是规则决定的，不算 bug。

## 分步

1. 调参不重新加载（第四节），先做，因为最影响体验；
2. 图层面板：把现有视图挪进去，统一中英文标签和图例；
3. 新图层，按这个顺序：
   1. 水系图
   2. 栖息地
   3. 高度和坡度
   4. 成玉程度
   5. 鱼群
   6. 两只兽关系

## 结果（2026-11-19）

主人确认：独立面板，6 个新图层都要。

老师的要求是 "make evidence for what I create"：不用懂算法，也能看到证据。主人追问：设置和图层怎么区分，才不会让人觉得重叠、困惑？

### 设置和图层的分工

- **设置 = 改变这座岛**：形状、水量、时间、速度、画质。调了以后，岛本身会变。抽屉顶部的小字改成"改变这座岛"。
- **图层 = 看见规则**：只读，打开或关掉都不改变任何东西。面板顶部写"看见规则"。

判断标准只有一句：**会改变世界的放设置，只是揭示的放图层。** 按这个标准做了搬家：

| 原来在设置里 | 现在 |
|---|---|
| 外观 → 地表视图（分区 / 密度） | 图层 → 地表 |
| 探索 → 尺度视图 | 图层 → 尺度对照 |
| 生灵 → 痕迹、目标（路线、脚印、状态、饮水、休息） | 图层 → 生灵 |
| 更多 → 水流粒子 | 图层 → 水 |

设置里只留了一条虚线提示："想看它怎么运作，打开「图层」 →"，点一下就跳过去。

技术向的 LOD 线框、山褶的五步拆解、骨架，仍然留在设置 → 更多。

### 图层面板（地图按钮上方）

- **地表**（一次选一个，都是给地面换颜色）：
  - 原貌
  - 高度（新）：从浅到深，每 5 米一条等高线，每 25 米一条粗线
  - 坡度（新）：从平到陡，超过兽能走的坡就变红
  - 山褶
  - 分区
  - 草被
  - 成玉
- **水**：
  - 水流粒子：瀑布上的红带按水速往下滑，图例里有说明
  - 水系图（新）：潭标成节点，并注明流量；出水口和溪流画成线，线越粗水量越大；瀑布落点画圈；标出主流和跌水潭
- **生灵**：
  - 栖息地（新）：家的候选 A/B/C 和归属、各自的岩窝、饮水点（标注"N 个，轮流用"）、草场（实时显示剩余草量百分比）
  - 路线
  - 目标
  - 两只兽（新）：两只之间一条虚线，标出距离；跟随对方去喝水或吃草时，标签变成玉色；让路时，头上显示"让路"
  - 鱼群（新）：在岛上的潭里，直接画出带路鱼的三圈规则范围、去向，以及"N 条 · 巡游 / 顶流歇息"
- **尺度**：尺度对照

**图例**：开了什么，左下角就出现对应的图例，所有图层合成一张。

**颜色**：都加进了 `palette.ts` 的 `LAYER`；CSS 里通过 `--layer-*` 变量取用。

### 调参不再重新加载

- **第一次进入和换岛**：仍然显示加载画面。
- **调地形、水、岛底**：旧岛留在原处，镜头和兽都不动，右下角显示"正在重塑岛屿 N%"，算好后一次换上新岛。

**修掉的问题：**
1. **白算一遍**：滑块停下后，场景马上用"新参数 + 旧地形"把兽、栖息地和岩窝白算了一遍，等新地形来了又算一遍，所以会卡两次。现在岛只用"建成时的参数"（`ground.built`）。
2. **寻路太慢**：
   - 每次寻路都要把整片区域重算一遍"能不能站"；现在每座岛只算一次地形部分，障碍物在每次寻路时再盖上去。
   - 岩窝的检查结果、石头的尺寸也都按输入缓存了。
   - 结果和原来完全一样，check-world、check-herd、check-den-clip、check-school 都通过。

**效果**（生产版本）：调一次参数，从"整页加载"变成换岛时停顿约 0.65–0.95 秒。这是在隐藏窗口里测的，实际应该更快。

**剩下的停顿**：主要来自找栖息地和生成地面贴图。要再降，得把这些挪到后台线程，可以下一轮再做。

### 补充（主人反馈）

1. **小地图点生物**：原来只打开"跟随"，不切换视角，所以从总览点过去镜头不动。现在走"生灵"这一章，镜头会飞到这只兽身边，在两只之间切换也会飞。
2. **栖息地**：去掉了"家 A/B/C"。每只兽只有一个家，就是它的岩窝。世界里的标签也不会再浮到图层面板上面。
3. **累计脚印和四脚**：原来设置里的这两项，放回图层 → 生灵，名字沿用原来的。
   - "累计脚印"和原先地表里的"成玉"是同一份数据，所以把"成玉"从地表里拿掉，避免重复。
   - 累计脚印是叠加层，可以和高度、坡度等地表视图同时开。
