# 白玉岛界面分层（2026-11-08）

四种用法不要混在同一层：

1. **浏览岛屿。** 左缘四个镜头只回答「去哪里看」：总览、山、水、生灵。它们不是时间。总览包含岛体、侧壁、岛底和垂下的水。
2. **调整世界。** 齿轮里的山、水、植被、光照。改的是生成或画面，不负责带你走动。
3. **观察生灵。** Life 镜头、生灵与时间、图鉴里的这一只。时间在这里是它的往返，不是太阳。
4. **检查程序。** 调试组后半。课堂两项可以打开给老师看。脚、骨架、导航诊断仍在，默认折叠。

左侧镜头不进设置。同一项不在两个一级组里各放一次。

## 低保真

默认浏览。岛是画面。左缘只有图标，当前项带名称。右上一个齿轮。

```
+--------------------------------------------------+
| 顶栏                                            |
| [图标 总览]                              (齿轮) |
| [图标]                                          |
| [图标]              整座岛                      |
| [图标]                                          |
+--------------------------------------------------+
```

设置打开。宽屏时抽屉在右，约 320 px。窄屏时从底部升起，不超过屏高的七成。下图的一级顺序以本轮实作为准；塑造岛屿与调试默认收起。

```
+---------------------------+------------------+
| 岛仍可见                  | 探索             |
|                           | 植被与光照       |
|                           |   灌木、草       |
|                           |   晨午暮夜       |
|                           |   环境视图       |
|                           | 生灵与时间       |
|                           | 塑造岛屿         |
|                           |   山体、水、岛底 |
|                           | 调试与性能       |
|                           |   路径与脚印     |
|                           |   开发诊断       |
+---------------------------+------------------+
```

## 迁移表

| 原名称 | 当前功能和数据来源 | 新位置 | 保留/移动/删除 | 默认可见 | 原因 |
|---|---|---|---|---|---|
| 岛屿图鉴 | 打开资源目录 `ResourceAtlas` | 探索 | 保留 | 是 | 浏览时查岛上有什么 |
| 认识生灵 | 打开同一目录并选中生灵卡 | 探索 | 保留 | 是 | 不是第二套页面 |
| 另一座岛 | `Island.seed` 换成由当前种子决定的下一个 | 探索 | 保留 | 是 | 换岛是浏览，不是手填参数 |
| 恢复初始 | `dwelling.reset`，清接触、回到卧位 | 探索 | 移动 | 是 | 访客从常用操作直接重开观察 |
| 只看风景 | 本地状态，藏起镜头条 | — | 删除 | 否 | 和「界面让给岛」重复，镜头条已经很小 |
| 低灌丛开关 | `View.shrubs` 布尔，只决定画不画 | 植被 · 数量滑条 `View.shrubAmount` | 移动 | 是 | 默认 1 与现在的疏密相同；松手后才重算 |
| 草量 | `View.grass`，地被密度 | 植被 | 移动 | 是 | 和灌木一样是植被，不是山 |
| 环境视图 | `View.envView` 正常 / 分区 / 密度 | 植被与光照 | 移动 | 是 | 可即时对照岛上的分区与密度 |
| 比例视图 | `View.scale`，人形标尺仍用 1.7 m | 探索 | 移动 | 是 | 看尺度，不是改生成。人形不进图鉴 |

| 时辰 | `Light.hour` 太阳弧，只改光 | 植被与画面 · 太阳时辰 | 移动 | 是 | 这是太阳，不放进生灵的天数 |
| Seed 输入框 | `Island.seed` | 调试 · 开发 | 移动 | 否 | 普通浏览用「另一座岛」；复现时再打开 |
| 休息处 A/B/C | `Dwelling.home`，同一只的三个候选家 | 生灵与时间，次级 | 保留 | 是 | 文案写明是候选家，不是三只生灵 |
| 生灵继续生活 | `Dwelling.run` | 生灵与时间 | 保留 | 是 | 播放 / 暂停 |
| 时间 1×/10×/30× | `Dwelling.speed` | 生灵与时间，标成生灵倍速 | 保留 | 是 | 只加快这只生灵，不推动太阳 |
| 倍速下的说明小字 | 静态句子 | — | 删除 | 否 | 名称已经说明 |
| 当前状态与往返 | `pose.activity` 与 `cycles` | 生灵与时间 | 保留 | 是 | `cycles` 是走完一趟再回家的次数，不叫太阳日 |
