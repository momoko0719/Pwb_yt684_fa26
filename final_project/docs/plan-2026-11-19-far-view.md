# 方案：远景优化——风格实验（2026-11-19）

主人的决定：
- 先做远景，开场引导和兽鱼规则先存着（已记在 `roadmap.md`）。
- 从着色器的角度试几种形式。
- 主人觉得《千里江山图》、敦煌壁画已经不太贴合现在的白玉岛，想找更贴合的意象。

参考图（主人发的）：
1. Sky 光遇：柔和的体积光，雾里一层层远岛；
2. 塞尔达：王国之泪的空岛：手绘笔触的岩壁，块面清楚；
3. 任天堂明星大乱斗的浮岛：明亮、细节密；
4. 日本墨绘：松、瀑布、山脚的雾；
5. 水彩：一层层远山，湿边，纸纹。

## 更贴合"白玉岛"的意象

白玉岛的本体是**白瓷 + 玉**：地面是白瓷，兽走过的地方变成玉。所以意象最好也从"瓷"和"玉"里找，而不是从青绿山水里找：

| 意象 | 是什么 | 对应的着色器做法 |
|---|---|---|
| **宋代影青（青白瓷）** | 釉在刻花的凹处积得厚，呈青绿；凸处釉薄，发白 | 按地形曲率着色：凹处积釉变青，脊线发白，边缘有釉光 |
| **白玉山子**（比如故宫的《大禹治水图》玉山） | 整块玉雕成一座山：有山、树、路、人 | 沿等高线刻线，陡坡上加刀痕排线，脊线抛光发亮 |
| **米氏云山 / 日本墨绘** | 山以墨色晕染，山脚以云雾留白 | 按坡向和坡度分几级墨色，山脚起雾，轮廓加一圈湿边 |
| **Sky 光遇式的柔光** | 暖光、冷影、空气感 | 包裹光照（光面暖、阴面带天空的冷蓝），远处融进天色 |

## 第一轮实验（只改地面）

在着色器里加了一个"远景风格"开关，在设置 → 更多 → 开发（Leva 面板）里，有 5 档：
- 关闭
- 影青
- 水墨
- 玉山子
- 柔光

另外有两个距离参数：从多远开始变（默认 60 米），到多远完全变（默认 260 米）。所以**拉近时还是现在的样子，拉远才渐渐变成风格化的画面**。

四种风格读的都是同一张高度图：凹凸（曲率，从周围四个点算出）、坡度、朝向、高度。地形规则直接变成了画法，这本身也是"证据"。

对比图：`docs/far-view-2026-11-19/compare.jpg`，左边是总览，右边是中景（看向山）。

### 观察

- **影青**：山的凹处积成青绿，脊线是白的，最像"白瓷 + 玉"。缺点是色块偏硬，边界太清楚。
- **水墨**：山变成墨色，山脚起雾，和墨绘、水彩那两张参考最像，很有"画"的感觉。但和白瓷地面的对比太强，像两种画法拼在一起。
- **玉山子**：等高线和刀痕让远处"看起来有很多细节"，最直接回应老师那句"拉远就丢了细节"。缺点是线太规整，像地形图。
- **柔光**：最接近 Sky，但这一版颜色偏黄、对比弱，还需要调。

### 还没处理的（远景的另一半）

这一轮只改了地面。远景"丰富不丰富"还取决于：
- **树**：远处可以并成"点苔"式的墨点或色团；
- **岛底和岩壁**：可以用塞尔达那种笔触或块面；
- **云和雾**：Sky 那种一层层的雾和远处的岛影；
- **水**：远处的高光和留白。

## 第二轮：不换风格，只"加细节"（2026-11-19）

主人澄清：老师的意思不是要换一种画风，而是远景太空，拉近才看得到细节。为什么参考图远看也很丰富，我们的却很空？

### 参考图远看丰富的原因

1. **明暗反差大**：凹处暗，凸处亮；岩缝、洞口、悬崖下有阴影。我们的山是白底上再叠白，明暗只差一点。
2. **材质颜色多**：草绿、黄花、灰岩、土黄，几种材质交错。我们的远景几乎只有一种白。
3. **中等尺度的纹理**：岩层、裂缝、笔触，大小正好在远看时一个像素到十几个像素之间，所以远看也能看出来。我们的细节都太小（草、脚印），或者太大（整座山）。
4. **小东西够多**：鸟、花丛、遗迹、成片的树。我们的树在远景里只是几根小黑棍。
5. **空气和层次**：一层层的雾、远处的岛影、云。

### 便宜的做法（不加几何体，拉近不变）

上面每一条都可以只用着色器里的计算，读已经有的高度图：
- **凹凸明暗**：从高度图算曲率，凹处压暗带冷色，脊线提亮；
- **岩层和裂缝**：只出现在陡坡上，沿高度画断续的横纹，顺坡向画裂缝；
- **地衣**：长在山上平缓的台阶处，颜色淡淡的；
- **大块色斑**：低频噪声，让石头有冷有暖；
- **加强明暗**：受光面和背光面的转折更明显。

全部按距离淡入：拉近（60 米以内）和现在一样，拉远到 260 米时完全生效。每个像素只多算几次采样和噪声，和镜头远近无关，比加模型、加贴图便宜得多。

开发面板里的远景风格加了第 6 档 **Detail（加细节）**。对比图在 `docs/far-view-2026-11-19/detail.jpg`：
- **总览**：山体的起伏、沟壑一下子出来了；
- **中景**：岩层、凹处的阴影让山"有了质感"；
- **近景**：基本不变，只在 60 米左右开始有一点淡纹，可以再把起点推远。

### 下一步可以做的（按效果和成本排序）

1. **调好"加细节"**：
   - 地面的阴影烘焙进光照图（后台线程里算一次，运行时零成本）；
   - 岩层、裂缝再自然一些。
2. **远处的树**：
   - 远处成片的松在地上加一块深绿色团（就是现在已有的"草被远景着色"的做法）；
   - 或者把林子画成点苔式的色点，让远景有颜色变化。
3. **地面的色彩分区**：
   - 草甸、湿岸、林下、石坡的颜色差别在远景里再拉开一点；
   - 可以加少量花色（参考 Sky 的黄花）。
4. **空气层次**：
   - 岛周围加一两层低雾带、远处的岛影、几只鸟；
   - 这些都是很便宜的平面或粒子。

## 第七轮：立体的云，以及时间转盘（2026-11-20）

**云**（`Cumulus.tsx`，在「加细节 + 空气」里）：
- 岛旁边放了四朵积云，每朵 160–310 米宽、90–150 米高，慢慢绕岛漂。
- 做法和 Weatherglass 一样，是步进的体积云：
  - 每朵云是一个盒子，里面七个软球拼出云团，平底；
  - 边缘被 3D 噪声啃掉；
  - 视线方向走 40 步，每一步再朝太阳看 4 步，所以云顶亮、云肚子灰，逆光时边缘发亮。
- 颜色取当时的天色和云色，所以会跟着时间变。
- 还没做：云在岛上投下的阴影。

**时间转盘**（`TimeDial.tsx`，左下角常驻）：
- 地平线上一条太阳弧，弧后的天空就是岛上这个时刻的天色；
- 白天是太阳，夜里是月亮；
- 拖太阳可以改时间。点「清晨 / 正午 / 黄昏 / 夜」，时间会沿最短的方向缓缓走过去，光照按原来的调色板逐渐过渡，不是跳过去的。

设置抽屉里原来那组时间按钮删掉了。生灵卡片右移到转盘旁边，图层图例上移到转盘上方。播放和倍速先不做。

## 第八轮：主人看过云和转盘后的修改（2026-11-20）

**时间转盘**：
- 改成一个小圆盘，转一圈就是一整天：正午在上，午夜在下，清晨在左，黄昏在右；
- 上半圆是这一刻的天色，下半圆是夜色；
- 去掉了四个预设按钮；
- 整体缩小成左下角一枚毛玻璃药丸（半透明白、背景模糊、上沿一道高光），右边是时间和名称；
- 默认时间改成 17:30，接近黄昏。

**云**：
- 不再挂在「加细节 + 空气」下面，单独一个开关：设置 → 更多 →「岛边的云」，默认打开。
- 图层 → 空气 →「云的构成」：显示每朵云的盒子（蓝线），和里面的圆形云团（橙色线框），说明云是程序生成的。
- 从四朵加到八朵：六朵在岛的高度或更高，两朵小的低在岛底旁边，所以从哪一侧看都有几朵靠近岛。
- 和远处的云堤用同一种颜色（调色板的云色混 62% 白），暗面往天空的蓝里偏，不发灰；密度调低一点，边缘更松；远处更多地融进天色。

**岛边缘的分割线**：
- 原因：远景细节让侧壁和顶面变成了两种颜色，它们交接处的那圈锯齿状接缝就露出来了。
- 现在顶面在离边缘最后 10 米、侧壁在最上面一截，都退回原来的白瓷色，交接处两边一样。

## 第九轮：阴影、亮度、岛底、云的位置和点击（2026-11-20）

- **阴影真正变软**：
  - 上一轮只取了周围 6–12 米，总览里只有两三个像素，所以还是硬的。另外原来软化只作用在加细节那一层，底下的白瓷本身还在用锐利的阴影。
  - 现在在载入时，把烘焙光照图在 CPU 上模糊一份（约 25 米，两次盒式模糊，接近高斯）。远处的白瓷底色和加细节都读这份模糊的，近处仍用原来的锐利阴影。运行时只多一次取样。
- **「加细节 + 空气」设为默认**。
- **默认时间改成 17:00**。远景的压暗减轻了：凹处压暗从 60% 降到 40%，背光面从 0.8 提到 0.9。
- **岛底和尖锥**：加强了五样东西：
  - 上下明暗，最下面压到 0.6；
  - 迎光、背光；
  - 肋条之间的凹槽，用网格自带的遮蔽；
  - 横向拉长的大块"沉积层"色斑，偏青绿或偏暖，是色块而不是线；
  - 更宽的风化水痕。
- **云的位置**：按开场视角摆。左边三朵、右边三朵（离视线 60–120°），岛后面高处两朵，正前方不放。每边最后一朵低在岛底旁边。云改成原地慢慢左右摆，不再绕岛转，也就不会转到前面来。
- **点击云**：点一朵云，它会从很小的云团重新"长"出来（2.5 秒），同时显示它的盒子和云团，并弹出一张毛玻璃小卡片，写着尺寸、几个云团、光照怎么步进算出来。再点一下关掉。

## 第十轮：梯台沉积、水的质感，以及三个小修（2026-11-20）

**梯台**（`builtMaterial.ts`），参照黄龙钙华：
- 立面挂着帘状沉积：每一幅宽窄不同，有的地方厚，有的地方光，不排成行；
- 平台顶面有一片片奶油色的钙华壳；
- 每一道瀑布流过的立面染上琥珀色，脚下湿处带一点青绿。瀑布的位置直接读水系，最多 12 道。

**水**（`flowWater.ts`）：
- 浅而慢的地方，池底沉着大片奶黄的淤泥；
- 水的最边缘有一圈琥珀色的钙华边；
- 流得快的水更淡、更偏青，像掺了空气。

这些在远处也能把一段水和另一段水分开。

**小修**：
- **点"总览"时画面下沉**：原因是镜头位置和看向的点各自走直线，中途视角会晃过头再回来。现在看向的点走直线，镜头绕着它沿弧线转，距离按比例变，视角只朝一个方向变。

  - 水彩（仿透纳）：Kuwahara 滤波把颜色抹成一块块水色；每块边缘积色变深；颜料沉在纸纹里；整体提向纸白；画纸边缘留白。
  - 油画（仿梵高《星月夜》）：每格画一笔，沿方向场排列（地上顺着明暗的等高线，天上是平滑噪声的旋度，所以会打旋）；每笔取它中间的颜色，横向有厚涂的弧面和刷痕；大小两层笔触叠在一起；饱和度提高，暗部推向群青、亮部推向铬黄；有断续的深蓝轮廓。
- 浏览器里试拍过每个滤镜，四张样片看过并调过：
  - 水墨原来太淡，加了褶皱积墨和米点；

  - 水彩的纸纹有方格，改了；
  - 油画从细碎的影线改成了一笔一笔的笔触。

## 第二十二轮（2026-11-21）：鱼卡岸边、饮水波纹

- **鱼卡在岸边抖动**：原因是受惊的鱼只朝"正背离白玉兽"的方向逃，被岸挡住后只在前方 ±90° 里找路，找不到就停在原地，但头还在两个方向之间来回转，看起来就是抖。改成：
  - 逃的方向在一整圈里找"离正背离最近、前方两段都是深水"的方向，所以碰到岸会顺着岸游走；
  - 前后都没路（会朝兽游回去）就停下不动，速度归零，不再来回转头；
  - 平时被浅水挡住时也在一整圈里找路，实在没有就停下。
- **饮水波纹**：原来是一个白色平环匀速放大。改成：
  - 前沿后面跟两三道细波，波峰略亮（映天光）、波谷略暗（深水色），像真实的水圈；
  - 先快后慢地扩散，越扩越淡；
  - 随水流向下游漂一点；
  - 碰到岸就停（按 16 个方向量出水面到岸的距离），不再画到沙地上。
  - 鱼受惊时溅起的小水圈用同一种画法，稍大一点。
- 开发时可在控制台用 `guixuRing(x, z, 大小, 秒数)` 手动放一个水圈看效果（只在开发模式）。
- 路线图里删去二十四节气；仙鹤暂不做（理由记在 roadmap.md 末尾）。

## 第二十三轮（2026-11-22）：图鉴植物编辑器统一

- 六种植物（低灌丛、草、花、松、伞冠树、垂枝树）都用同一个编辑器（`PlantEditor.tsx`）：左边模型和生长回放，右边规则、三根滑杆、「换一个 · 恢复 · 应用到岛上 · 定位」。每种植物怎么长写在 `plantModels.ts`。
- 低灌丛：L-system 逐代回放；滑杆 = 茎的数量、第一次分叉高低、叶的粗细。颜色下拉框删掉，改成「颜色圆环」：灰绿 / 赭黄 / 铁红三段，拖两个圆点改比例，旁边实时显示岛上各色有几片。默认比例沿用代码里原有的规则：灰绿 30%、赭黄 65%、铁红 5%。每片灌丛记下自己掷的数，所以改比例不用重新长灌丛。
- 松：L-system 逐代回放；滑杆 = 轮枝间距、枝的角度、平顶早晚。改过的松会按比例缩回原来的高度，高度仍由所在位置决定（真实尺度不变）。不动滑杆时与原来的松完全一样（已逐顶点核对），蓬莱岛不受影响。
- 草：不是 L-system，回放按岛上铺草的顺序一片片长；滑杆 = 每丛叶片、高矮、弯度（草的着色器加了一个弯度系数，默认 1）。
- 花：回放先抽茎（花苞），最后一齐开花；滑杆 = 每簇朵数、茎高、花头大小。
- 四种新编辑器都能「应用到岛上」，存法和伞冠树一样（每座岛的存档里 `plants`）。
- 所有文字进 `strings.ts`；图鉴里最后一处写死的中英文提示也改成字符串。
