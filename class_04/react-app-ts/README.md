# Clay Studio — Class 04

Interactive voxel / density / CSG / meshing / chunking lab for Procedural World Building.

## Run

```bash
npm install
npm run dev
```

## Firebase (Assignment 2)

1. Copy `.env.example` → `.env.local` and paste your Firebase web config  
2. Follow `../tutorials/Firebase Auth Firestore Storage Hosting.md`  
3. Deploy:

```bash
firebase use YOUR_PROJECT_ID
npm run deploy
```
